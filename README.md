# DSH 插件索引 · kinglhy2006

这个仓库是一份 DSH（DeepSeek Harness）格式 1 的插件索引。

在 DSH 里打开 **插件 → 发现 → 添加索引源**，填：

    https://kinglhy2006.github.io/dsh-market-index/index.json

（需要先在「插件 → 实验性插件」里打开「自定义插件索引」。）

## 收录

- dsh-voice-bridge — 贾维斯式语音助手（Windows）
- dsh-crt-theme — CRT 终端皮肤

索引格式见 https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/plugin-market.zh.md
